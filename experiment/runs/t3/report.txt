ROOT CAUSES:
1. `_scatter_clutter` (Rubble, Fungus, Bones, Puddle) used a hard-coded `FLOOR_Y := 0.0`. The real floor top is at y=1.05. The GridMap centres each cell on y (cell 0 is centred at y=1.0, the slab is 0.1 thick), and `surface_y()` returns 1.05. These four props sat at y 0..0.4, below the floor slab (underside 0.95), so the floor hid them. The audit reported BURIED for all four.
2. `_drop_small_props` (Skull, Candle, Bucket) set `prop.global_position.y` before `decor.add_child(prop)`. Reading the global transform of a node outside the tree logs `Condition "!is_inside_tree()" ... get_global_transform` (that error appeared in the headless console) and returns identity. The write then rebuilt the position from that identity, which reset x/z to 0,0. All three props ended up stacked in one column at the world origin (0, ~1.2, 0) instead of their intended spots. The audit reported ORIGIN for all three.
3. `_place_ahead_of_player` (Lantern, Chest) offset from the camera along `+cam.global_basis.z`. A Camera3D looks down -Z, so +Z is behind the camera. Both props landed at z of about 10.6 and 11.5, behind the camera at z=7. The audit reported NOT_IN_FRUSTUM against the near plane.
